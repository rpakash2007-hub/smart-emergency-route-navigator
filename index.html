About the Project

Smart Emergency Route Navigator is an intelligent navigation system developed for emergency vehicles such as ambulances. The system helps identify an optimized route between the ambulance location and emergency destination. It provides route information, distance, estimated travel time, traffic analysis and emergency traffic signal priority.
